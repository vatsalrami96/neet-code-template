# Low-level design (gate)

Amazon's SDE2 loop usually includes one round where you design and partly code a small system in about 45 minutes:
a parking lot, an elevator controller, a rate limiter, an in-memory file system, a vending machine, an LRU or LFU
cache as a class. Interviewers look for clean class boundaries, sensible interfaces, and the ability to extend the
design when a requirement is added mid-round.

This track is intentionally empty. Bring your own resource.

## To open the gate

1. Put the resource link or notes here.
2. Tell Claude "LLD resource is ready". Two mock slots in the final two weeks then switch from coding to design.
3. Practice designs go in this folder as `<date>-<name>.py`, plain Python, no framework.
